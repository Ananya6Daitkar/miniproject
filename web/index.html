What is implemented

Environment

A single machine group maintains a synthetic 50 km corridor divided into ten units. Gamma-distributed increments worsen condition; tamping reduces it. Travel and work must fit the current window.

Learning

Three-layer convolutional networks, twin Q critics, target networks, replay memory and a fixed entropy coefficient. The policy learns through simulator interaction, without labeled schedules.

Comparisons

A one-window CP-SAT optimizer, a fixed threshold rule and a no-maintenance control share the same scenario and objective. The CP-SAT baseline is myopic, not a global optimal reference.

Research boundary

This is an independent, scaled-down implementation inspired by the paper's publicly described method. Original field data, full equations and exact hyperparameters were unavailable. Project assumptions are documented.
